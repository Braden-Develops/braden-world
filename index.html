Minecraft Java Edition

braden.world

A small Minecraft network for friends: a main survival server plus extra worlds that admins can spin up on demand.

braden.world

Join

  1. Open Minecraft: Java Edition. Versions 26.2 and 26.3 both work. (On Bedrock? See Bedrock & consoles.)
  2. Go to Multiplayer → Add Server.
  3. Enter braden.world as the server address. No port needed.
  4. Click Done, then join. You'll start on the main server.

On Xbox, PlayStation, Switch, a phone or Windows Bedrock? See Bedrock & consoles.

Bedrock & consoles

Bedrock Edition players (Xbox, PlayStation, Switch, phones, tablets and Windows) join the same worlds as Java players. You sign in with your normal Xbox/Microsoft account.

1. Link your Java account (if you have one)

The main server is invite-only, and invites are for Java accounts. If you also play Java, link the two once and you'll play as your Java self on Bedrock: same name, inventory, homes and permissions.

  1. On Java, join the server link.geysermc.org and type /linkaccount. It shows a code.
  2. On Bedrock, join link.geysermc.org (port 19132) the same way you'll join our server (below), and type /linkaccount <code>.
  3. Both sides confirm the link. Follow the on-screen instructions if they ask for the steps the other way round.

Bedrock-only players (no Java account) can't be added to the main server's allowlist yet; ask Braden.

2. Phone, tablet or Windows

Play → Servers → Add Server, then enter braden.world and port 19132.

2. Xbox, PlayStation or Switch

Consoles can't add servers directly. BedrockConnect works around that: you change your console's DNS, and the Featured Servers list opens a server list where you can add any server.

  1. Change your DNS as above, then fully close and reopen Minecraft (restart the console if it doesn't take).
  2. Go to Play → Servers and join any featured server. Instead of that server, the BedrockConnect server list opens.
  3. Choose Connect to a Server (or Add Server) and enter braden.world, port 19132. Save it so it's there next time.

While your console uses that DNS, the BedrockConnect community server sees which addresses your console looks up. Set DNS back to Automatic when you're done playing if you prefer.

Troubleshooting

The featured server opens normally (e.g. The Hive's lobby)

The DNS change hasn't taken effect. Check it's set to Manual with the values above, then fully close Minecraft or restart the console.

"You are not on the allowlist for homeroom"

You joined as a Bedrock-only player. Link your Java account (step 1), or ask Braden.

It can't connect, and I'm on the same Wi-Fi as the server

Some home routers can't connect to their own public address from inside the network. Ask the host for the local address to use at home instead of braden.world.

"Outdated server" or "Outdated client"

Update Minecraft. If it still happens right after a Bedrock update, the server needs a moment to catch up; tell Braden.

Something looks or behaves slightly differently than on Java

Bedrock players connect through a translator (Geyser), and a few things don't translate perfectly. Report anything game-breaking.

Servers

braden.world is a network: one address, several separate worlds behind it. Each server has its own world, inventory and progress. You can hop between them without leaving.

Homeroom

Where everyone lands when they join. Survival, normal rules.

Extra worlds

Admins create more servers for events, builds or experiments. Type /server to see what's up.

Backed up nightly

Every world is backed up each night, so a disaster doesn't wipe your progress.

Allowlists

The network is invite-only: you need to be on the main server's allowlist to join at all. If you're not, you'll be disconnected with "You are not on the allowlist for …".

  • Request access below, or ask an admin to add you. They only need your Java username, even if you've never joined before.
  • Other servers are open to anyone who's on the network, unless an admin gives one its own allowlist. Trying to /server into one you're not on shows the same message, and you stay where you are.

Fair play

Anti-xray

X-ray mods and resource packs show fake ores everywhere. Real ores only appear once they're actually exposed, so mining is the only way to find them.

Everything is logged

Every block placed or broken and every item taken from a chest is recorded. Griefing can be traced to the player and rolled back.

Real accounts only

Every player signs in with a genuine Microsoft account, so nobody can pretend to be someone else.

FAQ

It says "Can't resolve hostname" or won't connect.

Double-check the address is exactly braden.world. If it still fails, the network may be restarting for an update; try again in a minute.

I'm on the same Wi-Fi as the server and braden.world doesn't work.

Some home routers can't connect to their own public address from inside the network. Ask the host for the local address to use instead.

Why does the server say 26.2 when I'm on 26.3?

The servers run 26.2 for plugin compatibility, and a translation layer lets newer clients join. Play normally; you won't notice a difference.

I got disconnected with "Proxy shutting down".

The network is being updated. It's usually back within 30 seconds, and nothing is lost: worlds are saved before every restart.

Can I use mods?

Performance and visual mods like Sodium or shaders work fine. Cheats aren't welcome, and anti-xray makes ore finders useless anyway.
