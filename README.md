# braden.world

Static site for the braden.world Minecraft network, served by GitHub Pages at https://www.braden.world.

- `index.html` - for players: how to connect, servers, commands, FAQ
- `admin.html` - for admins: LuckPerms, permissions, server management, allowlists, CoreProtect, operations
- `style.css` - shared styles (light and dark)

Plain HTML and CSS; no build step. Edit the files and push to `main` to publish.
